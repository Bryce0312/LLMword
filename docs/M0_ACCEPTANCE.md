## 结论

离线基础和实际本机 HTTP/SSE 集成验收通过，新旧应用测试共 **68 项通过，0 失败**。SQLite 数据库与工具处理器实际执行；模型响应使用协议模拟或注入 provider。真实 DeepSeek 原生工具调用仍待独立验收，M0 不标记为全部完成。

## 修复过的问题

独立检查发现并推动修复了原始 assistant 工具数组被修改、恢复重复扣工具额度、完成检查点与完成事件分离、恢复时静默更换模型，以及非字符串工具调用 ID。集成测试还发现 Windows 下先删除临时 SQLite 文件再停止测试子进程会导致 EBUSY；现按先停止自建子进程、后删除测试目录的顺序清理。

模型配置以模式、模型引用和不含凭据的端点配置指纹固定。配置变化进入 waiting，恢复原配置后继续，不会把旧 mock 运行交给新 live provider。私有 checkpoint 保存必要的模型协议消息；公开运行、快照及事件采用白名单，不导出 messages、reasoning_content、checkpoint 或凭据。

```powershell

```
