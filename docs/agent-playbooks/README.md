# 课程演示：研究员怎样分工

更新于 2026-11-19。本手册描述当前课程路径的代码与操作边界；实际运行、模型及来源模式以界面和[课程验收](../COURSE_ACCEPTANCE.md)记录为准。手册本身不会安装工具，也不证明预测准确率。

上课可以这样介绍：**用户问一句话，主 Agent 先说明按什么口径研究，再从十种研究方法中选三位研究员独立查资料；新信息来了，先判断需要局部补查还是全队复核。像素人物展示的是已保存的真实动作。**

## 一次演示怎么操作

1. 在默认入口写问题，选 24 小时、48 小时或 7 天，默认 48 小时，点一次“开始跟踪”。普通用户不用选研究员、工具或贴材料。严格模式可固定填写的时间、规则和来源。
2. 看“按这个意思研究”：系统会补常见假设、固定目标时间和近期参照。预设模式的常见细项尽量自动补全；无法取得报价时不能编价，有可读公开资料时可给明确标注的条件估计。
3. 看房间与任务卡：主 Agent 按题选三个不同职责，必须有核验席；每张卡有真实子任务与入选理由。人物工作、工具返回、报告气泡只由已提交事件触发，刷新历史不重演。
4. 看当前 Yes 概率、资料充分度、公开理由及来源关系。概率是对命题的估计，资料充分度说明依据覆盖；团队一致不代表事实已确认。未发布概率保持缺值。
5. 点“检查一次新资料”可演示监听路径。重复或无关信息保留原判断；普通增量交相关研究员与核验席两人，重大或冲突更新交本题原三人。曲线只增加真实发布点，不画未来外推。

## 十种目录，按题出场

主 Agent 不计入十人目录，也不会每题同时启动十人。下面是职责模板，具体名单以本轮保存的 `team`、任务和理由为准。价格问题、人事问题或社交动态可以出现不同组合；规则建议不等于每轮固定结果。

| 角色 | 本题需要什么时请他 | 手册 |
| --- | --- | --- |
| official 官方资料 | 公告、正式状态、指定判定来源 | [官方](official.md) |
| timeline 新闻时间线 | 新进展、首发、更正与转载 | [新闻](timeline.md) |
| industry 行业与专业 | 技术、产业或制度条件 | [行业](industry.md) |
| people 人物与组织 | 身份、任职、账号或组织关系 | [人物](people.md) |
| statistics 统计与指标 | 数字口径、单位、时期与价格参照 | [统计](statistics.md) |
| market 预测市场 | 市场参照与公开合约规则比较 | [市场](market.md) |
| social 社群与舆情 | 公开动态、传播线索与样本偏差 | [社群](social.md) |
| analogy 历史类比 | 相似条件、差异与失败反例 | [类比](analogy.md) |
| graph 关系图 | 实体、关系、影响路径与反证 | [关系](graph.md) |
| verification 反证与核验 | 每轮保留反证、来源与时间核查 | [核验](verification.md) |

协调与发布流程见[主 Agent](supervisor.md)。初始和全队轮为三人；`local` 必须为一位相关研究员加 `verification`，共两人。针对已取得的争议材料还可向一位角色补查一次，计入同一轮预算。

## 真正能调用哪些工具

所有课程角色可用 `search_web` 搜索、`fetch_page` 读取公开网页。搜索标题和 snippet 只是线索；读取并保存的正文或明确截断的片段才可引用。`partial` 表示可引用片段，不能声称读过整篇。官方角色有指定来源域名范围及失败后的替代公开来源处理，替代报道不能写成官方确认。

只有 **main、statistics、market** 额外可用 `get_market_quote`。目前只取 Coinbase **BTC-USD / ETH-USD 现价**并保存快照；不是股票行情接口、交易指令或 Polymarket 合约概率。时间是本系统取得报价的观测时刻，交易所成交时间未提供。模拟来源的报价标为虚构，不能当真实市场价格。其他角色没有此工具权限。

Worker 以 `submit_report` 结束调查，提交状态、摘要、实际读到的 evidenceId、支持、反证、缺口、可空概率和下一步建议。主 Agent 使用已注册的规范题、派工、分流、一次补查、候选发布或不足结束动作；正式发布还需程序验证，不会直接平均三位研究员的主观概率。

以下仍为目录中的 **planned 专用能力**：`search_official`、`search_news`、`deduplicate_events`、`search_domain`、`search_entities`、`read_dataset`、`calculate`、`read_contract`、`read_market_quotes`、`search_social`、`search_history`、`read_memory`、`query_graph`、`propose_graph_patch`、`search_counterevidence`、`verify_sources`。当前用通用搜索、网页读取和角色方法完成有限研究，不能宣称已接专门社交账号流、数据库计算器、盘口、图处理器或图写回。`await_reports`、`set_watch_plan` 等也不是当前模型可调用工具；等待和固定间隔唤醒由执行器处理。高级 M1 的材料工具许可不改变课程网络权限。

## 记忆与监听怎么讲

记忆是同题、同版本、截至本轮起点的历史判断、报告摘要与关系，带来源轮次；不是模型训练，也不是本轮新证据。新报告要引用的材料仍须本轮实际读取。面板分别说明上一判断、本轮新信息和为何调整。

监听保存查询词、已见内容、检查时间与分流理由。执行器按服务端配置检查并去重；主 Agent 根据新材料选择 `local`、`team` 或不更新。当前不是每个角色自行永久轮询或自主改频率；浏览器关闭后仍需服务端进程运行。到期、停止、来源失败和预算耗尽都保留真实状态，不能显示成功假气泡。具体配置与预算看 `/api/v1/course/config`。
