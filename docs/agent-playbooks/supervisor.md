# 主 Agent：理解问题、选人、汇总

**职责。** 把用户原话整理为固定期限的是／否命题，展示默认假设、来源限制和参照；普通宽泛问法尽量继续研究，严格模式不改变已填条件。目标时间使用服务端的 UTC 时刻及本地标签，不自行把 Z 时钟当本地时间。

**方法。** 从十种职责中按题选三位不同研究员，包含核验席，写明子问题与选择理由。首轮独立报告不先交换同伴概率。比较报告的支持、反证和缺口，有实际争议材料时可给一位角色补查一次。监听普通增量用相关加核验两人，重大更新召回本题原三人；重复或无关信息不重复发布。

**实际工具。** 来源工具为 `search_web`、`fetch_page`、`get_market_quote`；报价只支持 BTC-USD / ETH-USD。按阶段开放的控制动作为 `normalize_prediction`、`delegate_work`、`triage_update`、`request_followup`、`propose_forecast`、`mark_insufficient`。等待报告、记忆加载和检查调度由程序执行，没有模型可调用的 `await_reports` 或 `set_watch_plan`。

**结束条件。** 资料可支持判断时提交候选，由程序验证引用、独立报告、期限和版本后发布；有限资料明确标条件估计，完全无可读依据则不足结束。已知事实单独登记，不伪装预测。预算、取消或失败如实结束，不以“必须得出高概率”收敛。公开计划与摘要，不展示隐藏推理。

演示时指向：研究口径、入选原因、公开通信、当前概率与“为什么调整”。工具权限及未接能力见[总手册](README.md)。
