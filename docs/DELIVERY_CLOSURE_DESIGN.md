# 交接前收口设计（2026-11-21）

用户授权按设计继续本地实现、mock及真实测试；组长要求十类研究员按问题选三类，姓名与贡献表暂不填写。未经用户再次通知不上传GitHub。沿用Node/SQLite与像素研究室。

## 路径与取舍

保留十类角色和既有动态三席编排，补齐方法/能力边界、公开工具与十类可执行覆盖；不把每题改成十人同时调用。默认团队仍三种不同职责含核验，增量复核保留原规则。

用户补充可移植性要求后，默认仍用既有DeepSeek服务，不依赖本机Edge、登录状态或固定地区网络。支持任意语言查询及市场意图元数据，兼容旧中英文news参数。Bing仅作显式启用的可选适配器，按使用时的网络响应记录请求引擎、实际域名、跳转与失败；不把本机探测结果写死，不使用已退役BingSearchAPI，不引入Azure账户。每次新闻搜索最多三路、每路最多三条。未启用/验证码/拒绝时如实回退并保留原因，不把摘要登记为正文。fixture不触网。

新证据策略quoted-claims-v1随新任务/派工固定。Worker支持/反证及主Agent的研报发现、预测依据携带逐条原文片段；核验引用归属、本人已读、片段实际存在及直接数字覆盖。原子主张与推断分开展示。该守卫验证片段出处及基本覆盖，不能证明任意自然语言逻辑蕴含；保留独立核验与限制。旧运行不迁移、不改封存报告。

新案例使用香港天文台红色火灾危险警告，避免依赖额外行情权限。固定目标时点后首次成功获取（不晚于5分钟）的官方warnsum快照，WFIRE/code=WFIRER且非CANCEL即Yes；完整有效快照未包含红色警告即No。目标前不结算，晚于观察窗口/来源失败/时间异常保持不可核验。观察规则明确为目标后的首个有界快照，不冒称精确秒级历史状态。

预测与结果分开保存。结果证据独立归档，不追加到旧预测Run，原概率/来源/时间不回写。结算无需模型或Key，只允许固定官方URL；存结果与逐份Brier、资格/模拟标识，单题评分不称准确率已验证。默认关闭付费监听。

## 验证与交接

- 十类角色方法与实际许可一致，模拟问题矩阵覆盖十类且每题三席；来源失败不能变成成功。
- 引用伪造/串Run/缺片段/数字错引/推断标签、旧数据兼容与取消恢复。
- Bing两路、任意语言、重定向白名单、超限、验证码、回退与mock零网络。
- 同一新题mock完整发布到核验。最初授权的一次真实预测上限160000tokens，实际111070tokens未发布；用户另行明确授权修复后一次最多80000tokens，实际64880tokens。一次只汇总恢复仍被取得时刻守卫误拒，修复后在原期限内重验同一原候选完成受控闭环；不列完整自动成功。Key只由用户在网页保存，详情保留在质量报告。
- 重复/过早/迟到/无效JSON/模拟洗白/预测已知结果/评分隔离；全量回归与浏览器检查。
- 更新交接、实际运行证据与本地代码包，保留全部旧失败和报告。交付不包含Key或运行数据库。

实施顺序：搜索与十角色 → 逐条片段守卫 → 官方警告工具与结算 → mock与回归 → 真实试跑与结果核验 → 交接包。
