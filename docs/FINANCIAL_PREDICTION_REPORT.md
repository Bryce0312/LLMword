初始上下文相互独立，核验席如实声明未收到同伴正式报告，未冒称逐字审阅其他席；主Agent在汇总阶段比较三份报告。三个独立职责不等于三个独立交易所来源。后续若要求“核验席逐份核对其他席完整报告”，应增加显式会后核验阶段并单独验收，不能把本次独立检查改称已完成该步骤。
