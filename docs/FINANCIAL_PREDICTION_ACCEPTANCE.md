# 金融预测真实验收设计（2026-11-21）

用户授权现在进行金融预测真实验收，确认后才上传GitHub。本轮选BTC-USDT价格方向，保留原Coinbase工具，另用Binance公开行情专用适配器，市场/统计/核验三席必须全部完成。学号、姓名及贡献声明仍由小组填写。

既有到期API仅支持警告题，不能冒称价格题已有自动评分。新增受严格契约触发的价格核验子集：本轮市场研究员首次成功取得的BTC-USDT现价作为不可变基准；目标后5分钟内首次成功取得的同接口现价严格高于基准为Yes，等于或低于为No；网络/无效数据/错过窗口不结算。获取时刻是系统观察时间，不是精确成交时刻。固定来源、交易对、规则和版本，不接受客户端自填结果或更换基准。

计划在创建真实题时设约30分钟后的目标。三席各自读取报价及可选近30个已关闭分钟桶；统计仅计算这段样本的收益/波动，不称历史校准或因果。近期K线与Binance现价是不同口径，K线仅作研究上下文，不能替代固定现价结算。三个独立Agent不是三个独立市场来源。

调用沿用既有短窗口独立上下文、顺序模型执行及公开报告摘要汇总。初次160000token上限，实际128780tokens未发布，保留price-live-attempt-one.json。用户随后要求提高上限并继续优化，修复版新任务上限300000tokens，研究员各80000tokens/最多6次模型、主Agent最多8次；旧案例预算与用量不追改。工具固定到必要行情。此价格契约的正常发布要求三类初始报告全部有效且各自引用本人取得的匹配现价；缺任何一席则不得以两席通过。维护重验原候选入口不扩展到价格题。本轮正常验收不使用维护发布。

新一轮进一步修复：数字用无损十进制规范化比较，尾随零等价但不同数值仍拒绝；取得时间明确作为systemObservedAt保存在工具正文；JSON引用仅容忍字符串外空白，不替伪造的子集右括号背书，错误回执给出本人已读的真实短片段。模型只接收分钟桶统计摘要，原始K线另存证据，不重复传三份数组。任何价格席无法完成时立即停止，无需付费走无效汇总。

“最新”分为固定基准、汇总前新观察、到期结果三条时间线。三席完成后系统再读取一次现价与最新已关闭分钟桶供主Agent使用；发布时间的新观察最多两分钟旧，超过则重新刷新后再汇总。初始基准不改变，结果只在固定目标后读取。各时刻均保留，不能把旧报告快照写成刚取得的价格。

先验证涨/平/跌、早/晚、网络失败、跨资产/来源/模式、固定基准与旧证据不变、三席/摘要及重开幂等，再调用真实模型。到期核验不调用模型。真实期间不改该实例代码；如发现缺陷保留失败，先修复验证，再决定新尝试，绝不回填预测时间。

通过条件：三个初始角色实际完成带片段报告，核验席完整，正常自动发布于截止前，摘要与结构化时间/价格一致，结果在约定窗口由固定接口读取，逐题Brier及模型用量存证，无维护发布/人工结果。预测对错另行记录，单样本不代表准确率。更新只读案例、报告和本地源码包；GitHub保持不动。

预检中Coinbase与数个其他公开源在本机超时；本次契约在创建前改定实际可达的Binance，不在结果时静默换源。USDT不等同USD，原BTC/ETH-USD工具保留原行为。

接口依据：[Binance市场数据专用入口](https://developers.binance.com/en/docs/products/spot/faqs/market_data_only)、[公开行情字段](https://developers.binance.com/en/docs/catalog/core-trading-spot-trading/api/rest-api/market)。
