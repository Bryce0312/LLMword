# 模型／资料服务故障与原题恢复

2026-11-19，课程交付版。对应 A10、A11、A14；本轮修复服务故障处理，不改变预测主题或切换为模拟回答。

## 故障发生在哪里

用户两条天气题在首个模型 HTTP 请求失败：1 次模型尝试、0 次工具、0 位研究员，没有发布预测。旧代码只保存 MODEL_HTTP 并丢失具体 HTTP 状态，所以不能事后把旧档案强行改写成某个已知错误。资料服务的 402 与官方可用状态诊断提供了恢复线索；随后极小真实模型请求恢复 HTTP 200。

官方定义中，402 是余额不足，401 是鉴权失败，429 是限流；这些与模型是否理解“红磡”无关。[DeepSeek 错误码](https://api-docs.deepseek.com/quick_start/error_codes/)、[官方余额接口定义](https://api-docs.deepseek.com/api/get-user-balance/)。凭据与余额金额不写入公开记录。

## 现在如何处理

| 类型 | 系统行为 |
| --- | --- |
| 模型／资料 402、401、403 | 明确显示余额、凭据或访问原因，立即停止本轮后续请求，监听标记 paused_provider，取消下一次唤醒 |
| 模型 429、408、5xx 或临时连接故障 | 主 Agent 在预算内最多尝试三次，所有尝试计入预算；等待可取消，仍失败则保留失败记录 |
| 原问题准备阶段失败 | 即使尚无 predictionId，也提供“重试本次调查”；在同一任务新建轮次，保留问题、创建时间、原固定期限及失败历史 |
| 已发布过预测后遇故障 | 保留上一次有效预测；错误不能生成概率点，也不能伪装“没有新信息” |

接口只公开静态安全代码、httpStatus、有限的 retryAfterMs 和 actionRequired；不透传模型服务错误正文、账号、URL 密钥或私有消息。搜索摘要仍不能作为已读原文，失败不产生证据 ID。硬错误先保存失败回执再终止；新轮次成功后清除暂停状态。

前端失败条使用错误状态颜色，详细原因集中一处，避免重复泛化报错。轮询仅 GET，不会因页面刷新自动重试或切 mock；用户恢复服务后点击重试，成功的新轮不再显示旧轮错误。多人协作与答案来源的既有归属保持。

## 验收

故障修复批次全套 **216/216** 通过。其中独立 HTTP 用本地合成模型验证：402 一次即停／暂停、同一未准备问题手动恢复并保留失败历史、503 一次失败后成功且每个请求计入预算。另覆盖 429 退避中取消、来源 402 不再继续取证、错误正文不泄漏及前端恢复入口。合成故障测试不消耗真实模型额度，也不作为天气预测准确率证据。

两条原天气问题通过实际页面重试，沿用 Pro 思考模式、真实搜索／读取与原问题记录。实际结果保存到 [天气恢复摘要](evidence/weather-recovery-live-summary.json)；未来结果未到期时不宣称准确率。天气来源须区分区域预报、点位代理及已经观测的雨量；香港显著降雨概率并不等于红磡任意可测降雨的概率，不能无说明硬套。

首题运行成功后还发现输出契约边界：模型生成的规则把“实况／预报”都列为 YES 判据，最终文字又说明尚未形成降雨实况，因此不适合作严格评分样本。新建预设降雨题现已统一由服务端写入“实况才确认、预报只作概率依据”的规则。准备阶段的来源缺口与最终限制分开保存，汇总可提交已更新的 sourceLimitations（包括空数组）；未提交时明确标注为准备阶段记录。旧封存不回写，不以此做 Brier／准确率结论。

## 第二条原题的独立问题

“香港红磡会下雨吗今天”的重试已经真实派出 official、statistics、verification；其中两位完成报告，但研究员及最后汇总出现 MODEL_INCOMPLETE，最终未发布。与此同时，“今天”被默认24小时窗口覆盖成明日上午，属于另一个时间理解错误。旧任务已停止跟踪，原失败、来源、预算与错误日期契约均保留；不能把旧记录改成修正成功。

新建问题中的无具体时刻“今天／今日／today”按创建时当地日期的23:59:59.999固定，主 Agent、研究员、校验与监听使用同一时刻。跨日重试不能把今天顺延，过期不再消耗模型调用；严格模式明确 targetAt 优先，已有契约不迁移。具体钟点、绝对日期不在这个简单日终解析器的范围内，继续按原模型／严格模式路径处理。

新预设降雨题还在服务与存储两层禁止凭通用网页自动登记已知YES／NO，返回 WEATHER_OBSERVATION_REQUIRED，允许模型转为发布概率。当前没有结构化实况证明工具，不能仅凭页面标题、文字或URL把预报认作观测。自动天气结算留待专门验证的实况连接器，不作为本次交付已完成能力。

深度模式此前有8192输出硬上限；增加等待时间不能解决这个限制。新轮思考模式默认16384，显式配置允许到32768，保留全轮300000与研究员65536的累计预算。截断仍不能当报告或概率保存，不进行同配置盲重试。供应商返回的安全数值 usage 在截断时也计入实际消耗；不能把未完整返回的输出当免费调用。提高上限不保证更准确，也不能排除上下文长度等其他不完整原因。

失败任务现在也能停止跟踪；停止不会删除失败或已有判断。
