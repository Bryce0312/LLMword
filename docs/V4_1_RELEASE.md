# V4.1 课程交付记录（2026-11-22）

基线：V4.0 `72b35acffa086cc2d2809250089fbe26603091f1`。本次仅发布同仓库 V4.1，不合并、不建 PR、不改队友历史。对应 M2/M4 课程子集与 A03/A04/A06/A08/A10/A11/A14；不是完整平台里程碑验收。

## 改动

- 通用二元题的新运行：Fetch 先按原合同保存证据/工具回执，再向模型投影最多约 1,200 个 UTF-16 单元的三个精确片段（含开头、两个词项相关窗口）。英文词、中文双字匹配不需要模型或新增依赖。URL、证据 ID、内容哈希、发布时间及取得时间不变。省略标记不是原文，不能跨标记引用。
- `fetch_page(url, focus)` 优先展开本轮本人已读且包含定位词的同一证据，不新增网络请求或证据编号。定位词不在已保存片段中时沿用原 Fetch 行为，可能产生另一份截取快照。当前适配器只保存其取得的最多 4,000 字片段；**不是完整原网页归档**，模型可见的也不是全文。
- 保留现有 Search 默认两条、最多五条、摘要 400 字及 URL 去重；不在获取原文前把摘要当证据。不删除反对来源，也不把词项相关性当作语义立场判断。长文可能仍遗漏关键反证，需核验席定向展开。
- 新通用运行准入同时计入序列化输入 UTF-8 bytes、工具 Schema、完整输出上限、2,048 协议余量和并发中的预留。bytes 是保守准入估计，不是实际 tokens。研究员不得消耗最后两个全轮请求及 `2 × (输出上限 + 16,000)` 汇总预留；研究员本身也提前进入仅报告阶段。没有提高总预算或压低正常输出上限。
- 未知用量单独保守预留并持久化，不冒充供应商实测。真实截断的已知 usage 仍累计。预算事件说明 `RUN_FINAL_RESERVE`、输入/输出额度或请求次数原因；`WORKER_INPUT_BUDGET` 为研究员准入失败；供应商错误、截断和预算不足保持区分。
- 预算未能完成时保存明确程序回执，或结束为 insufficient 且不发布概率；不称程序回执为 Main Agent 裁决。额度足够的路径保留真实角色调用、主 Agent 比较、定向复查与裁决。DeepSeek assistant 消息、tool_call_id 及协议要求的 reasoning_content 没有被删除，界面不展示隐藏推理。
- 既有固定警告、BTC、财报专用预算策略与旧运行检查点不迁移。历史概率、结果、团队记录和材料不回写。
- 前端减少重复模型连接/历史入口与说明口号；保留主导航模型连接、课程案例、证据及高级材料入口。协作结果增加按 URL 合并的“来源与研究员”列表，明确同源复用、支持/反证两用及尚无结论。不同 URL 仍可能是转载，不能据链接数声称来源独立。

## 可复现操作

Windows（Node >=22.17；本次使用 Node 24.22.3）：

```powershell
npm.cmd ci
npm.cmd run start:mock
```

打开本机终端显示的地址，输入“【模拟】虚构城市科技展未来48小时会正式开幕吗？”，关闭自动跟踪后提交；结果页查看角色报告、引用与来源关系。mock 不需要 Key，不是真实新闻验证。

```powershell
npm.cmd test

```

## 工具选型与限制

现有 DeepSeek Search/Fetch 接口和原提取方式沿用，没有更换抓取服务。比较对象是现有固定片段与新增本地轻量精确摘录；基准不是成熟检索库的性能竞赛。考察了 [FlexSearch CJK 编码](https://github.com/nextapps-de/flexsearch/blob/master/doc/encoder.md)：成熟索引具备中文分词支持，但本轮只有每页数千字、小候选集，不引入索引生命周期与新依赖。该库没有安装，未复制代码。更复杂 HTML 正文抽取/搜索融合留待真实抓取数据评估。

[DeepSeek 官方思考与工具调用文档](https://api-docs.deepseek.com/guides/thinking_mode/)要求工具连续调用保留 reasoning_content；本版只投影工具结果，不剪掉模型协议历史。私有 reasoning 仍局限在模型边界与既有私有检查点。

## 未完成与提交边界

- **本轮未做真实 DeepSeek 端到端验证。** 当前任务没有已验证的用户专用 Key 注入工具，云浏览器也不能访问本执行环境的模型连接页。不读取其他任务的 Key，不把桌面 Personal Vault 当云端环境变量。
- 既有 `WORLD_API_KEY` 和本机 live 页面“模型连接”可用于由用户自行启动的环境；后者只保存到服务进程。不要把 Key 发到聊天、命令参数、截图或 GitHub。不能宣称该本机方法已打通本次云任务。待有明确安全通道后，仅执行另行授权的一次窄范围 live 验证，不能自动付费重试。
- 加权/有符号证据评分暂缓：当前 support/counterevidence 是报告主张分类，不能直接映射成事件 Yes/No 或任意百分比。展示可审计引用关系，概率仍由已有发布合同独立管理。没有新增展示 LLM、完整图推理或自动语义评分。
- 课程权重：多 Agent 设计 30%、实现 25%、动机/分析/提交各 15%。演示应展示真实角色分工、工具回执、证据交换、核验分歧与边界；像素动画不是推理证明。旧 BTC 真例是单次流程，不是金融建议、收益保证或准确率证明。团队姓名/学号/真实贡献及课程提交材料仍由团队确认。
