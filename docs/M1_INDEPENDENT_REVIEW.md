# M1 后端交叉审查

日期：2026 年 11 月 18 日。当前交付范围按用户最新指令收紧为 binary（是／否）。本文记录可复现的后端检查，不代表完整 M1、M2 或课程 P0 已验收。

## 审查范围与独立性

本次交叉审查对象是由其他成员编写的 `server/domain/contracts.mjs`、`domain-store.mjs`，以及主集成人员新增的 `workbench-service.mjs`、`workbench-http.mjs`、`http.mjs` 调度和 `runtime/research-service.mjs` 可信角色绑定。也只读检查了 `start.mjs` 的启动接线。审查者只在 `domain-audit.test.mjs` 和本文落盘独立检查与结果，没有修改这些实现。

角色目录 `agent-catalog.mjs`、旧案例适配器 `legacy-import.mjs` 和 M0 的 Worker/Provider 由本审查者参与编写，不能作为独立自审成果。测试中需要经过这些依赖时，独立结论仅针对外部存储、服务边界及其持久化效果。

测试使用真正的 Node SQLite、临时磁盘数据库、事务与关闭重开；模型部分仅使用协议夹具。HTTP 检查使用内存请求流与响应夹具，调用真实 API 调度器和工作台处理器，不冒称 socket 网络端到端测试。未读取 `.env` 或服务凭据，未调用付费 API。

## 发现并复验的问题

| 问题 | 修复及独立回归 |
| --- | --- |
| 普通 replay 主题可改成 provided，再编辑预测题，从不可评分变为可评分；反向修改也会遗留资格 | 主题创建后 `sourceMode` 不可变；独立测试确认修改返回冲突，编辑题目仍不可评分 |
| replay 主题中手动提供的材料可以获得可评分标记 | 业务存储按主题约束资格；原采集方式可保留 provided，`scoringEligible` 强制为 false |
| 创建或编辑完整问题时可直接写入 active、closed、resolved 等系统状态，缺少相应运行或结算事务 | 本轮公开问题写入仅接收 draft、ready；独立测试确认不能凭 PATCH 伪造运行、关闭或已解决状态，失败不增加题目版本 |

这些问题已同步给实现者，并由独立测试验证当前修复。未来开放关闭或结算操作时，应另建带权限、证据和事务校验的专用路径。

## 已验证的边界

1. 写入幂等键及其输入指纹落入 SQLite。重开数据库后，相同请求返回原结果；不同输入复用同键冲突。相同更新重试先命中旧回执，不会被旧 `expectedVersion` 错误阻断。旧题目版本仍保持原内容。
2. `firstSeenAt`、`retrievedAt` 和正文哈希由服务端写入。用户提交更早取得时间或伪造哈希不会生效；再次提交相同不可变材料保留第一次接收时间。历史截点不能读到当时尚未接收的材料。
3. 证据关联不能跨主题；只关联同主题第一题的材料不会进入第二题。失败关联写入回滚，不留下半份资料；同一证据编号不能替换正文。
4. categorical、numeric、ranked_list 在草稿创建时也会被拒绝，不通过草稿形式绕开本轮 binary 限制。
5. 可信运行绑定拒绝未配置的模型引用，以及未接通的工具或槽位；拒绝时不会排入运行。允许的角色与槽位工具合并后进入运行许可，运行中的角色版本、公开身份、指令和题目版本已持久冻结。
6. 运行预算逐字段取角色限额与服务端执行上限的较小值。高角色限额不能抬升执行上限；更低限额不会被默认值抬高。
7. 工作台将所选 Skill 版本解析为冻结的方法文本。题目版本、角色版本和材料选取均进入运行快照。角色或题目稍后编辑不改变旧运行；原幂等请求仍返回原运行，不同输入复用同键冲突。
8. 原始证据的 `firstSeenAt`、`retrievedAt`、`publishedAt`、`contentHash`、`sourceMode` 在运行快照中保留，另记 `inputSnapshotAt`。另一题专属材料不能被传入该运行，另一题的最新运行及预测便签也不会被更新。
9. replay、未就绪、已过停止发布时间、没有材料的题目均在排入实时运行前被拒绝。研读结果没有被写成已发布预测，工作台的 `forecast` 保持 null。
10. 在模型响应前中止服务，保留未完成运行；重开两个 SQLite 存储后，角色模板可以是新版，旧运行仍恢复其原角色与题目版本，使用原指令完成报告。
11. HTTP 入口向外报告 binary 能力，拒绝其他题型、迟到版本写入、伪造 resolved 状态、注入角色或工具权限，以及指定任意私有文件路径的迁移请求；返回结构化 400／409，失败不排入运行。

本次范围内的可复现缺陷已修复，当前 11 项交叉测试没有阻塞失败。实际网络 HTTP／SSE、服务启动命令及页面交互由集成负责人另行验收，本文不替代这些记录，也不宣称真实模型自主调查已通过。
