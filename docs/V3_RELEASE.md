# V3.0 发行说明

验证日期2026-11-21。本版在原仓库[`Bryce0312/LLMword`的`V3.0`分支](https://github.com/Bryce0312/LLMword/tree/V3.0)维护。基线为V2.0提交`9add50bf4392ee2f921c6e23b6a9aa7e3cfff1e0`，V2.0分支及前面同学的提交历史保留。

## 改动范围

- 保留并整合既有mock/live运行隔离、模型连接、像素研究室及执行框架；版本元数据更新为3.0.0。
- 十类方法按题选择三席；市场报价基准、财报专项研究、支持/反证和逐报告裁决可追溯。
- 任意语言检索意图、新闻合并和可选Bing透明回退，无本机Edge依赖；搜索摘要不能作为正文证据。
- 逐条fact/inference和已读原文片段；本人、本轮、时间、数值及JSON匹配守卫，精简上下文和有界恢复。
- 固定警告规则及严格BTC-USDT规则的独立结果核验与单题评分；金融三席全部完成后才发布，汇总前刷新数据而初始基准不变。
- README运行指南、十类分工、真实网页截图、架构、已知边界与下一位交接入口更新。
